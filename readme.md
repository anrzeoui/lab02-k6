## 6. Threshold / SLO

### Baseline-ийн p95
`227.40 ms`

### SLO тооцоолол
SLO-г baseline × 1.5 гэж сонгосон:  
$$\text{SLO} = 227.40 \times 1.5 = 341.10\text{ ms}$$

### Шалгуур ба туршилтын үр дүн

#### 1. PASS Тохиргоо
- **Тохиргоо:**
  - `p(95) < 341 ms`
  - `http_req_failed < 1%`
- **100 VU тестийн үед:**
  - $p_{95} = 226.09\text{ ms}$
  - Error Rate = $0.00\%$
- **Үр дүн:** **PASS**

#### 2. FAIL Тохиргоо
FAIL гаралтыг харуулахын тулд түр хугацаанд босгыг дараах байдлаар тохируулсан:
- **Тохиргоо:** `p(95) < 1 ms`
- **Туршилтын дүн:** $p_{95} = 225.63\text{ ms}$
- **Үр дүн:** **FAIL**

 Дараа нь SLO-г буцааж `p(95) < 341 ms` болгон хэвийн болгосон.

- 100 VU үед систем өндөр throughput-ийг алдаагүйгээр боловсруулсан.
